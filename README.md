## 功能说明

该教务管理系统有四个登录角色，分别为管理员、教务员、教师与学生。

1、管理员拥有系统内最高的权限级别，因此能够访问所有的功能模块及其子功能。

​	管理员管理：允许进行管理员账户的增加、信息的更改以及账户的删除等管理活动。

​	教务员日志查看：列出所有教务员，可以通过点击进入查看日志页面。

​	教务员权限管理：提供了对管理员的权限赋予、删除操作，此外，还支持对教务员用户资料进行添加、修改和删除的操作。

​	学院管理：提供了对院系资料的查看、新增、修改以及移除服务。

​	专业管理：提供对专业信息的检索、录入、更新及删除操作。

​	教务员功能：提供教务员用户拥有的所有功能包括学籍信息管理、教师管理、课程管理等功能。

​	教师功能：提供教师用户拥有的所有功能包括录入学生的成绩、查询课程安排等功能。

​	学生功能：提供学生用户拥有的所有功能包括成绩查询、选课等功能。

2、 教务员

​	个人信息：编辑教务员的个人信息，在输入邮箱绑定后，可以在忘记密码后找回密码。

​	学籍管理：提供对学生的学院、专业和班级资料进行修改。此外，系统也支持学生资料的检索、新增及移除功能。

​	教师管理：提供包括查询、增加、修改以及删除功能，针对权限所属学院内的教师执行这些操作。

​	考试管理：支持对必修和选修课程的考试信息搜索、增添及删除功能，考试信息包括考试时间、考试时长、考试科目等信息。

​	课程管理：提供对选修及必修科目执行搜寻、增添、修改及删除等操作。此外，还允许用户对教师分配的课程进行调整，以及对班级	的课程表进行新增、编辑等管理活动。

3、 教师

​	学生课程查询：可以根据班级信息去查询学生，及其课程表。

​	课程安排：呈现现行的授课计划，包括课堂时间和具体课程内容。

​	成绩发布：对学生课程考核的成绩进行发布或更新。

​	处理学生申诉：当学生对公布的成绩提出质疑并申请复议时，教师有权根据具体情况调整分数或否决该请求。

4、学生

​	课程表：允许当前登录的用户查看其课程安排、授课时间等相关信息。

​	成绩查询：可以查询到学习课程的考试成绩，在对成绩认为不合理时可以对成绩进行申述重审，一门课程只能申述一次。

​	选课：提供各学院选修课的选择，显示课程的选择人数和上课时间等信息。

​	已选课程：显示选中的选修课程，同时可以取消选中的课程。
